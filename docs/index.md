## Описание репозитория

Вы находитесь в репозитории учебной дисциплины "Vibe Coding: AI-боты для бизнеса" реализующейся преподавателями [факультета инфокоммуникационных технологий](https://fict.itmo.ru) Университета ИТМО.

> Преподаватели тоже учатся, хорошие преподаватели учатся всю свою жизнь.

Мы постарались создать курс, который поможет менеджерам и специалистам с IT-уклоном создавать полезные продукты без глубоких знаний программирования. Используя современные AI-инструменты, вы сможете автоматизировать рутинные задачи и создавать ботов для решения реальных бизнес-проблем.

Не бойтесь спрашивать и искать интересные решения в рабочих заданиях - мы постараемся вам помочь и ответить на все вопросы. Дерзайте! 

## Описание учебной программы

Этот курс научит вас создавать Telegram-ботов для решения бизнес-задач, используя AI-инструменты вместо написания кода вручную. Вы узнаете:

- Как использовать LLM для генерации кода
- Как создавать ботов с нуля без программирования
- Как подключать ботов к данным и API
- Как деплоить ботов и собирать обратную связь
- Как улучшать продукты на основе фидбека пользователей

**Для кого этот курс:**

- Менеджеры проектов
- Product-менеджеры
- Специалисты с IT-уклоном
- Все, кто хочет автоматизировать рутинные задачи

**Не требуется:**

- Глубокие знания программирования
- Опыт разработки
- Сложные технические навыки

## План обучения

**Успешное прохождение учебной программы подразумевает выполнение следующих заданий:**

4. **[Лабораторная работа 3](labs/lab3.md)** - деплой и сбор обратной связи

## Методы оценивания

**Для получения оценки 3 (удовлетворительно):**

- Выполнить 3 лабораторные работы на 60-75%
- Бот работает и выполняет базовый функционал
- Есть отчет и демо

**Для получения оценки 4 (хорошо):**

- Выполнить все 3 лабораторные работы на 75-90%
- Бот работает стабильно, есть улучшения
- Качественный отчет с анализом

**Для получения оценки 5 (отлично):**

- Выполнить все 3 лабораторные работы на 90%+
- Бот решает реальную бизнес-задачу
- Собрана обратная связь от пользователей
- Внесены улучшения на основе фидбека
- Отличный отчет с выводами и рекомендациями
